# 🎮 Minecraft Roulette - Roleta Horizontal

Uma roleta horizontal interativa com itens, blocos e mobs do Minecraft!

## ✨ Features

- 🎯 **Carrossel Horizontal** - Design moderno com animação suave
- 🎨 **Tema Minecraft** - Cores inspiradas no jogo
- 📊 **Estatísticas** - Acompanhe seus giros
- 📜 **Histórico** - Últimos 20 giros
- ✅ **Filtros** - Escolha Items, Blocos ou Mobs
- 📱 **Responsivo** - Funciona em todos os dispositivos

## 🎮 Como Usar

1. Selecione quais categorias deseja (Items, Blocos, Mobs)
2. Clique em **GIRAR!** para girar a roleta
3. Veja seu resultado e o histórico
4. Use **Reiniciar** para limpar as estatísticas
